# `CLS-E0002` — `SchemaParseError`

> **`.cls.json` failed to parse** as valid JSON conforming to the v0.5.0 schema.

## When you see it

- A truncated or corrupted artifact (process killed mid-write).
- A hand-edited artifact with a syntax error.
- An artifact produced by a non-compile-lens tool that does not match the schema shape.

## What to do

1. The cause chain (under `╰─▶`) carries the underlying `serde_json` error including a line + column. Open the file at that position.
2. Validate against the JSON Schema:
   ```bash
   npx -p ajv-cli ajv validate -s schema/v0.5.0.json -d <your-file>.cls.json
   ```
3. If the file was produced by an older compile-lens, the right error is usually [`CLS-E0007`](cls-e0007.md) (migration) — re-check the artifact's `schema_version`.
