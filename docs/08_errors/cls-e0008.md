# `CLS-E0008` — `SensitivePathDetected`

> **Refused to record a path under `~/.ssh`, `~/.aws`, or `~/.gnupg`.** These directories are
> protected on principle — compile-lens never embeds them in an artifact.

## When you see it

A collector encountered a path that traverses one of the refused directories — typically:

- A user's home `.ssh/` key path leaking into a stack-trace frame.
- A file-watcher hitting `~/.aws/credentials`.
- A workload that opens its own GPG keychain.

This is a deliberate hard stop, not a configurable check — see the redaction policy.

## What to do

1. Remove the offending path from the workload's filesystem reach (or move credentials
   out of the default location for the duration of the capture).
2. If a benign tool legitimately needs to reference such a path, file an issue with the
   call site so we can scope a sanctioned escape hatch.
