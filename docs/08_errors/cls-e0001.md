# `CLS-E0001` — `IoError`

> **Failed to read file.** The OS refused or could not satisfy a read attempt.

## When you see it

- `cl collect /nonexistent.log` — the path you passed does not exist.
- `cl diff base.cls.json head.cls.json` — one of the artifact paths is missing.
- A collector tries to write to `.compile-lens/` and the directory is not writable.

## What to do

1. **Check the path exists** (`ls`, tab-completion).
2. **Check process permissions** (`stat -c '%a' <path>`).
3. **If the path was correct yesterday**, look for a moved repo / changed `cwd` / unmounted volume.
4. The cause chain (printed under `╰─▶`) names the underlying OS error (e.g. *No such file or directory*).
