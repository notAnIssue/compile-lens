# `CLS-E0009` — `RedactionPolicyDemotionRefused`

> **`cl scrub` will not downgrade a redaction policy** (e.g. `default-strict → internal`).
> Redaction is a one-way, lossy transform — once data is scrubbed it cannot be reconstructed.

## When you see it

```bash
cl scrub session.cls.json --to internal
# error if the artifact's policy is already default-strict / public-safe
```

The opposite direction works (`internal → default-strict`, `default-strict → public-safe`)
because every step is strictly more redaction, never less.

## What to do

If you genuinely need raw data, **re-collect** with the looser policy from the start:

```bash
cl collect --redaction internal -- python train.py
```

Then `cl scrub` can normalize down to `default-strict` or `public-safe` before sharing.
