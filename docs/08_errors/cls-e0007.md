# `CLS-E0007` — `MigrationRequired`

> **The artifact's `schema_version` is older than this analyzer expects.** Run `cl migrate` first.

## When you see it

You upgraded compile-lens and re-ran an analyzer against an artifact captured by an older
collector (e.g. `0.5.0` artifact, analyzer expects `0.6.0`). The N-1 compatibility window
covers one minor version back; older artifacts need an explicit migration step.

## What to do

```bash
cl migrate path/to/old.cls.json --output path/to/new.cls.json
# then re-run the analyzer
cl recompile-summary path/to/new.cls.json
```

`cl migrate --dry-run` shows what would change before writing.
